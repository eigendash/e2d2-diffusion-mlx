E2D2 toy experiment: encoder-decoder block diffusion vs decoder-only block diffusion
Paper: arXiv:2510.22852 (Encoder-Decoder Diffusion Language Models for Efficient
       Training and Inference).  This is an independent toy-scale implementation;
       nothing here is comparable to the paper's reported numbers.

host           : macOS-15.7.7-arm64-arm-64bit / arm64
mlx            : 0.32.3
task           : [BOS, d1, d2, d3] then the same block reversed, M = 16
prompt space   : 4096 distinct prompts
sequence       : 2 blocks x 4 tokens = 8
vocabulary     : 18 tokens ([BOS]=0, digits 1..16, [MASK]=17 last)
train / held-out prompts: 1024 / 1024 (disjoint, total space 4096)
training       : 5000 AdamW steps, lr 0.001, batch 64, t grid 32
loss           : weighting=uniform, context_blocks=1 (prompt block kept clean)
seeds          : [0, 1, 2]
